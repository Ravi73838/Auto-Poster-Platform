# Auto Poster Platform - Admin Portal Page Inventory & Test Matrix

This document provides a comprehensive inventory of every screen, route, required permission, role visibility, API endpoints called, interactive forms/actions, step-up/maker-checker requirements, states, and i18n namespaces across the Auto Poster Admin Portal.

---

## 1. Role Access & Permission Overview

* **SUPER_ADMIN**: Full platform administrative access. Holds all permissions (`*`). Can access every view, resolve escalated disputes, configure system settings, approve sensitive adjustments/refunds, manage team roles, and attest launch readiness.
* **MODERATOR**: Daily operations & verification staff. Holds `kyc.approve`, `campaign.approve`, `photo.approve`, `dispute.resolve`, `audit.view`, `strike.manage`, `announcement.manage`. Accesses work queues, driver & company verification, campaign review, photo review, disputes, strikes, and announcements. Blocked from financial pages, settings, and team role management.
* **FINANCE**: Accounting, treasury, and reconciliation staff. Holds `payout.approve`, `audit.view`, `dispute.resolve`. Accesses escrow payments, driver payouts, trial balance, ledger explorer, refunds, settlements, and financial audit logs. Blocked from KYC, campaign review, photo review, discipline, and settings.

## 3. Shell & Global Elements Inventory

1. **Top Header**:
   * Brand Title: Auto Poster Platform with Role Badge (`SUPER_ADMIN`, `MODERATOR`, `FINANCE`).
   * Global Search / Command Palette Trigger: `Ctrl+K` button opening `<CommandPalette />`.
   * Keyboard Shortcuts Trigger: `?` button opening `<KeyboardShortcutsModal />`.
   * Environment Ribbon: Displays `OTP authentication is DISABLED (testing mode) Auth Mode: Password Only`.
   * Language Switcher: Switches interface between English (`en`), Hindi (`hi`), and Gujarati (`gu`).
   * Theme Switcher: Switches theme tokens between Light and Dark modes.
   * Account Status Warning: If admin account is `SUSPENDED`, shows red warning banner disabling write actions.
2. **Left Sidebar Navigation**:
   * Permission-filtered links: Items render only when user's role has permission (`hasPermission(user?.role, item.permission)`).
   * User Info & Actions: Displays admin email, role, "Change Password" button (`/change-password`), and "Log out" button (`/admin/login`).
